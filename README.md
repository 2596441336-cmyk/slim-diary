# 瘦身日记

一个放在手机主屏幕上的减脂小应用：记体重、看趋势、算每天该吃多少、拍照或一句话记饮食、饮食日历，还有一个了解你情况的私人 AI 助手。

**在线使用：** https://2596441336-cmyk.github.io/slim-diary/

## 装到手机上

- **iPhone**：用 Safari 打开上面的网址 → 分享 → 添加到主屏幕
- **安卓**：用浏览器打开 → 菜单 → 添加到主屏幕 / 安装应用

第一次打开时填写性别、年龄、身高、体重和目标，之后随时可以在「我的」里修改。体重单位是**斤**。

## 功能

**今天**
- 一张「营养成分表」：今天还能吃多少、目标、运动加回、已经吃了多少、蛋白质够不够
- 早餐 / 午餐 / 晚餐 / 加餐分开记录，点一条可以修改份量或删除
- 记录方式：拍照识别、说一句（比如「中午吃了半份黄焖鸡米饭」）、搜索食物库、手动输入
- **提前规划**：点日期右边的「›」可以翻到明天、后天，最多 14 天后，提前把要吃的加进去，也可以一键按推荐排好
- 运动：跑步、慢跑、快走、散步、徒步按**公里**记，其他运动按时长记；消耗按体重自动估算，也可以填手表上的数字。只按一半加回预算，因为手表和 App 通常会高估消耗
- 吃超了不会标红，体重看的是一周的平均

**体重**
- 每天的数字会因为水分、盐分、经期上下波动，所以主要看平滑后的**趋势线**
- 趋势体重、已经减了多少、每周变化、预计哪天到达目标
- 自动分析：今天的起伏是不是水分、是否进入平台期、减得太快还是太慢、腰围变化
- 最近四周的周报：平均体重、趋势变化、平均摄入

**每天吃多少**
- 用 Mifflin-St Jeor 公式算基础代谢，乘上活动量得到每天的消耗，再按你选的速度减去缺口
- **会自动校准**：记录满 10 天后，根据你实际吃了多少和体重实际变了多少，反推出真实消耗，调整每天的目标
- 设有安全底线（女性 1200、男性 1500 千卡，且不低于基础代谢的 90%）
- 蛋白质目标约为每公斤目标体重 1.5 克

**助手**（需要 DeepSeek 密钥）
- 像聊天一样随时提问：「今天推荐吃什么」「这周为什么没瘦」「火锅怎么点」
- 每次提问都会附上你的资料、今天吃了什么、还剩多少热量、最近 7 天和体重趋势，所以回答是按你的情况来的
- 推荐的餐会变成卡片，点「记为已吃」就记进今天；说「帮我记一下……」它会整理好让你确认
- 一次最多发 9 张照片，可以用键盘麦克风说，回答可以朗读
- 可以让它帮你规划明天或之后几天的饮食，卡片会直接加到那一天的计划里
- 聊天记录只存在手机上，只带最近 12 条发给 AI

**食谱**
- 饮食日历：按月看每天吃了多少（正常、偏少、超出用不同颜色），点开某天能看到每顿吃了什么、热量、备注和照片
- 每顿饭可以写备注、存照片。照片压缩后约 150KB 一张，只存在手机里
- 导出到手机日历：把某天、某周或某月的每一顿饭导出成 iPhone 日历事件（单向导出，之后修改不会同步）
- **今日食谱推荐**：82 种搭配，按今天剩下的热量额度安排还没吃的餐，每天都不一样，避开最近 7 天吃过的；也可以让 AI 重新安排

**我的**
- 头像、昵称、记录天数、连续记录、已减多少
- 个人资料 · 目标与热量 · AI 设置 · 饮食偏好 · 我的食物 · 提醒与日历（饭点提醒加到手机日历）· 数据与备份 · 关于

**食物库**
- 334 种常见食物：主食、早餐、家常菜、外卖快餐、火锅食材、汤、肉蛋豆奶、蔬菜、水果、零食、饮料、西餐、调料
- 数值是常见做法、常见份量下的估算值（参考公开的食物成分数据，菜品按标准用料和烹调油推算）
- 「我的食物」：自己添加常吃的东西，比如便利店饭团、公司食堂套餐，以后搜索、AI 识别都会优先用

## 接入 DeepSeek（可选）

不接 AI 也能使用记录、分析、日历和食谱推荐。接上之后多了：私人助手、拍照识别、一句话记录、AI 安排食谱。

1. 打开 [platform.deepseek.com](https://platform.deepseek.com) 注册并登录
2. 充一点钱（几美元能用很久，识别一张照片不到 1 分钱）
3. 在 API keys 里创建一个密钥
4. 在应用的「我的 → AI 设置」里粘贴密钥，点「保存」，再点「测试连接」

默认设置：接口地址 `https://api.deepseek.com`，模型 `deepseek-flash`（支持图像理解），关闭思考模式。都可以在「高级设置」里改。

**密钥只保存在你自己的手机上**，不会上传到任何别的地方；导出备份时也不包含密钥。使用 AI 功能时，你的问题、相关的饮食和体重数据、照片会发送给 DeepSeek。

### 如果「测试连接」一直失败

可能是手机浏览器不允许网页直接连接 DeepSeek。可以免费搭一个中转：

1. 注册 [Cloudflare](https://dash.cloudflare.com)，进入 Workers & Pages → 创建 Worker
2. 把 [`relay/cloudflare-worker.js`](relay/cloudflare-worker.js) 的内容粘贴进去，部署
3. 复制 Worker 的网址（类似 `https://slim-relay.xxx.workers.dev`），填到应用「高级设置」的「接口地址」里

中转只负责转发请求，不保存任何内容和密钥。

## 隐私

所有记录、照片和聊天只保存在你手机的浏览器里。请从主屏幕的图标打开，这样数据最不容易被系统清理。换手机或清除浏览器数据之前，在「我的 → 数据与备份」里导出备份（可以选择是否包含照片）。

## 说明

这个应用的建议适合一般健康的成年人，不能代替医生或营养师的意见。如果你有慢性病、正在服药、怀孕或哺乳，每天吃多少请先问医生。

## 技术

纯静态网页（HTML + CSS + 原生 JavaScript），无需构建，GitHub Pages 托管。

```
js/core.js       数据存储、热量目标、体重趋势、自动校准、分析
js/foods.js      食物数据库与搜索
js/recipes.js    食谱库与每日搭配
js/ui.js         通用界面工具
js/photos.js     照片压缩与本机存储（IndexedDB）
js/ics.js        导出到手机日历
js/ai.js         DeepSeek 接口（拍照识别、一句话记录、AI 食谱、流式对话）
js/assistant.js  私人助手
js/calendar.js   饮食日历与今日推荐
js/me.js         「我的」各页面
js/app.js        今天、体重、记录流程、标签切换
relay/          Cloudflare 中转（备用）
```
